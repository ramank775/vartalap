# Vartalap UI Implementation Roadmap

This document tracks the implementation progress of missing UI functionality compared to industry-standard messaging apps.

## 🟢 High Priority (Core Messaging & Usability)
- [ ] Implement True Background Execution for `taskq` to handle uploads when app is exited.
- [ ] Implement Image Integration (Profile Pictures & Channel/Group Images) across all UI screens.
- [ ] Implement "Reply to Messages" feature (swipe-to-reply or long-press context menu).
- [ ] Add Chat List Indicators:
  - [ ] Show real-time "Typing..." / "Recording audio..." status in the chat list.
  - [ ] Add Read/Delivered indicators (blue/grey ticks) to the last message preview.
- [ ] Implement Online/Last Seen Status in the App Bar.
- [ ] Add "Forward Messages" functionality to select and send messages to others.
- [ ] Create a Global Settings Menu:
  - [ ] Add *Account & Privacy* section (Read receipts, Last seen visibility, Blocked contacts).
  - [ ] Add *Notifications* section (Custom ringtones, vibration settings).

## 🟡 Medium Priority (Enhanced Experience & Utility)
- [ ] Add Voice Notes UI (recording and playback).
- [ ] Implement Global Search (searching across all messages and contacts).
- [ ] Add Pinned Chats and Archived Chats functionality.
- [ ] Create a Media Gallery in Chat Info to compile all shared media, links, and documents.
- [ ] Implement In-Chat Search.
- [ ] Add Group Admin Controls (promoting/demoting admins, restricting messaging to admins).
- [ ] Implement Mute Notifications & Block User UI functionality.

## 🟠 Low Priority (Advanced Features & Polish)
- [ ] Add Message Reactions (emoji reactions on long-press).
- [ ] Implement Message Staring/Bookmarking.
- [ ] Add Rich Link Previews for URLs inside chats.
- [ ] Add Disappearing Messages (auto-deleting timers).
- [ ] Implement Voice and Video Call UI (initiation buttons in App Bar).
- [ ] Add Stickers and GIFs support.
- [ ] Implement Chat Customization (custom wallpapers/themes per chat).
- [ ] Add a Status/Stories tab.
- [ ] Add a dedicated Calls Tab (history and missed calls).
- [ ] Implement App Lock (biometric/PIN authentication).
- [ ] Create Linked Devices UI management for web/desktop companion apps.
- [ ] Implement Broadcast Lists or one-way Channels.
